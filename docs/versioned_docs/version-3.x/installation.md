### [Main Package](https://www.nuget.org/packages/Parbad/)
Including Mellat, Asan Pardakht, Melli, Saman, Parsian, Pasargad gateways.

Nuget Package Manager:
```
Install-Package Parbad
```
.NET CLI:
```
dotnet add package Parbad
```

### Web Integration

#### [ASP.NET CORE](https://www.nuget.org/packages/Parbad.AspNetCore/)
