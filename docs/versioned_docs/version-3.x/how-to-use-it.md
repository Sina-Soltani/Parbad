1. [Install Parbad main package and any other packages you need](./installation.md)
2. [Depend on your web application type, install one of the Web Integration packages](./installation.md#web-integration)
3. [Choose a Storage](./configuration.md#storage)
4. [Configure Parbad and gateways](./configuration.md#gateways)
5. [Request a payment](./payment.md#requesting-a-payment)
6. [Verify a payment](./payment.md#verifying-a-payment)
